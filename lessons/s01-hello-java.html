Decoder

Compiler errors you'll probably meet today

error: missing return statement

Java checks that every path through a method returns a value. In Two Sum you "know" an answer exists, but Java doesn't. After your loop, add something like throw new IllegalArgumentException("no solution");

error: cannot find symbol … class HashMap

You used HashMap without importing it. Add these at the top of the file, under the package line:

import java.util.HashMap;
import java.util.Map;
error: ';' expected

Every statement ends with a semicolon in Java. It's not optional like in JS. The error points at the line after the missing one surprisingly often, so check the line above too.

error: incompatible types: int[] cannot be converted to int

You returned the wrong shape. The method signature promises one type and you handed back another. Read the return type in the signature again.
